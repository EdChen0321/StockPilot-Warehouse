# 商品採購指南

[回到專案首頁](../README.md) · [工廠生產指南](production-workflow.md)

## 使用目標

這份指南適合負責向供應商採買**現成商品**的人員，帶你完成叫貨、分批收貨、費用確認、入庫配櫃與結案。

如果需要委託工廠製造商品、另行採購材料並記錄用料，請使用 [工廠生產指南](production-workflow.md)。商品採購不處理付款或應付帳款。

## 前置條件

- 系統已啟動，可開啟「採購與物料 → 商品採購／叫貨」。
- 商品庫已建立啟用中的單品 SKU；套組需依組成單品採購。
- 已在「物料與採購 → 供應商」建立並啟用供應商，也可從採購表單的「管理供應商」進入。
- 需要安排出貨時，先準備符合商品品質、包裝及出貨條件的櫃位。

## 操作流程

```text
新增採購草稿 → 確認叫貨 → 登記本次收貨 → 查看入庫／補費用 → 配櫃
                            ↳ 未收齊：下批到貨時繼續收貨
                            ↳ 收齊：自動結案
                            ↳ 不再到貨：取消未收部分並結案
```

**叫貨不增加庫存；確認實收才增加庫存。入庫與具備出貨資格是兩件事。**

### 1. 建立採購草稿

在列表按「新增商品採購」，填寫以下資料後按「保存草稿」。

| 欄位 | 填寫方式 |
| --- | --- |
| 採購單號 | 使用尚未使用的單號，方便與供應商單據對照 |
| 供應商 | 選擇本次叫貨對象 |
| 商品 SKU、訂購數量 | 選單品 SKU，數量為正整數；同一 SKU 合併成一列 |
| 參考單價 | 可留白；不是本批最終入庫成本 |
| 預計到貨日、備註 | 選填，記錄交期與需要追蹤的事項 |

需要多個品項時按「新增商品」。保存後應看到草稿與採購明細，此時庫存不變；仍可按「編輯草稿」修改品項。

### 2. 確認叫貨

核對供應商、SKU 與數量後，在詳情按「確認叫貨」，確認提示內容。

狀態變成「已叫貨／待到貨」。商品與訂購數量固定，仍不增加庫存；交期及備註可透過「調整交期／備註」更新。確認後若需追加商品，另建採購單。

### 3. 登記這一批實際收到的商品

商品到貨後，在原採購單按「登記本次收貨」。每批使用獨立的「本次入庫單號」，只填這一批實收數量，不填累計數量；未到的品項填 `0`。

| 欄位 | 填寫方式 |
| --- | --- |
| 本次實收數量 | 不超過畫面顯示的剩餘待收量；至少一個品項大於 0 |
| 本批實際單價 | 填此次收貨的單價；未知可留白，明確零元填 `0` |
| 本批實際運費 | 填整批實際運費；未知可留白，免運填 `0` |
| 本批稅費 | 依實際費用填寫；未知可留白，沒有稅費填 `0` |
| 運費分攤方式 | 選擇「依件數」或「依貨款金額」 |

按「確認本批收貨並入庫」後，系統建立本批入庫單及逐件庫存，更新採購單的已收與待收數量。未收齊時為「部分到貨」，收齊時為「已收齊／結案」。

**費用留白表示待補，不代表免費。** 可以先收貨，再補齊費用；不要為了通過表單而把未知金額填成零。

### 4. 查看入庫、補費用並配櫃

在採購詳情的「分批收貨紀錄」按「查看入庫」，核對本批 SKU、件數及費用狀態。需要補填或更正費用時，在入庫單按「修改費用」。費用修訂會同步影響本批商品的相關成本分析，包含已出貨商品，保存前應再次核對。

接著從收貨紀錄按「配櫃」，或從入庫單進入配櫃流程。完成後核對尚未配櫃件數；商品必須放入符合品質、包裝及出貨條件的櫃位，才具備出貨資格，仍受占用與退貨等狀態限制。

### 5. 繼續收貨或取消餘量

後續到貨時，回原採購單重複第 3、4 步，不另建重複採購單。

如果供應商確認不再交付剩餘商品，按「取消未收部分」，填寫原因後確認。已收到的商品與庫存保留，只取消剩餘待收量。草稿則可用「取消草稿」結束。

結案後不可繼續收貨或修改採購內容；若仍需採購，另建單據。取消餘量不是退貨，也不會扣除已入庫商品。

## 範例：訂 100 件，分兩批收貨

以下是數量說明，不會在系統自動建立資料。假設原庫存為 0，期間沒有出貨或其他異動。

| 操作 | 已收 | 待收 | 取消量 | 本次庫存變化 |
| --- | ---: | ---: | ---: | ---: |
| 確認叫貨 100 件 | 0 | 100 | 0 | 0 |
| 第一批收 40 件 | 40 | 60 | 0 | +40 |
| 第二批收 60 件 | 100 | 0 | 0 | +60 |

如果第一批後確定剩餘 60 件不會到貨，改為取消未收部分：已收 40、待收 0、取消 60，原本的 40 件庫存保持不變。

## 完成後驗證

- 在採購列表用單號、商品／SKU、供應商或狀態找到原單。
- 在詳情核對「訂購數量 = 已收 + 待收 + 取消數量」（適用已確認叫貨的單據）。
- 每次實收都有對應入庫單，明細件數與當批實收一致。
- 費用未知時顯示「待填費用」，補齊後再核對費用狀態與分攤結果。
- 展開「操作歷史」，可查叫貨、交期調整、分批收貨與取消紀錄。

## 常見問題與排錯

| 遇到的狀況 | 處理方式 |
| --- | --- |
| 找不到商品或供應商 | 確認主檔已建立且啟用；商品必須是單品 SKU |
| 無法修改商品或訂購數量 | 只有草稿可修改品項；已叫貨單可調整交期或取消未收餘量 |
| 提示超過剩餘待收數量 | 核對是否把累計實收填成本批實收，並查看先前收貨紀錄 |
| 提示入庫單號已存在 | 先查原入庫單是否已保存；不要換單號重送同一批到貨 |
| 提示採購單已更新 | 重新整理後核對最新狀態，再操作，避免覆蓋別人的變更 |
| 保存後斷線或結果不明 | 先查原單與分批收貨紀錄，確認有無入帳再決定是否重試 |
| 商品已入庫卻不能出貨 | 核對配櫃、品質、包裝、櫃位出貨設定，以及占用／退貨狀態 |

本指南未提供已確認收貨的任意撤銷流程。若已保存的數量有誤，保留單號與原始單據，先查明再處理；不要用取消餘量或重複收貨抵銷錯誤。
