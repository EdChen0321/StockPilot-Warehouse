# 工廠生產指南

[回到專案首頁](../README.md) · [商品採購指南](goods-purchases.md)

## 使用目標

這份指南適合負責與工廠協作的人員，帶你建立生產單，依工廠回報叫料、登記材料實收與實際用量，再分批接收成品。

本流程不要求先建立 BOM。若只是向供應商購買現成商品，請使用 [商品採購指南](goods-purchases.md)。

**物料目前只記總庫存，不區分工廠或存放位置；成品則使用逐件庫存與櫃位。** 單據上的產品工廠是協作對象，不代表系統已有工廠別物料庫存。

## 前置條件

- 系統已啟動，側欄可進入「採購與物料 → 物料與採購」。
- 商品庫已有啟用中的成品單品 SKU。
- 「供應商」已建立並啟用產品工廠及物料供應商。
- 「物料」已建立材料、基礎單位及所屬供應商；填寫數量時須沿用該單位。
- 準備工廠回報、實收及實際用量等依據，不以預計需求代替實際異動。

## 操作流程

```text
建立生產草稿 → 確認生產下單
                  ├─ 工廠回報缺料 → 關聯物料採購 → 物料實收 → 登記實際用料
                  └─ 成品送達出貨倉庫 → 登記成品實收 → 入庫補費用與配櫃
```

物料與成品各自記帳。成品到貨不會自動扣料；登記用料也不會自動增加成品庫存。實際用量可依工廠回報另行補登。

### 1. 建立並確認生產單

進入「生產計畫」，按「新增生產計畫」。填入計畫單號、生產商品、產品工廠與預計生產數量，按「保存生產草稿」。預計成品到貨日與備註可選填。

核對內容後按「確認生產下單」。狀態變成「已下單」，此時不扣物料、不增加成品庫存，也不會自動依 BOM 預留材料。

### 2. 依工廠回報建立物料採購

工廠回報缺料時，在生產單按「依工廠回報叫料」。選擇物料供應商，填寫採購單號、材料與叫貨數量，按「保存採購草稿」，再在採購單確認「確認叫貨」。

- 不同供應商分開建立採購單；材料必須屬於所選供應商。
- 核對「來源生產單」與「送往產品工廠」，避免掛錯單。
- 叫貨只建立紀錄，不增加物料庫存，也不會自動通知廠商。實際聯繫與配送仍需另行安排。

保存後可在原生產單的「關聯物料採購」找到這張採購單。

### 3. 登記物料實收

收到工廠的實收確認後，從關聯採購進入物料採購單，按「登記本次收貨」。填寫本次收貨單號及本批數量，確認物料驗收入庫；未收到的項目留白，不登記收貨。

可以分批收貨，每次不得超過剩餘未收量。保存後增加物料總庫存，成品庫存不變；在採購到貨紀錄與物料歷史帳核對數量。

系統不會因「送往某工廠」而建立該工廠的獨立物料帳。若需要知道每間工廠各有多少材料，目前流程無法直接提供。

### 4. 登記實際用料

工廠回報已使用的材料後，在生產單按「登記實際用料」。填「本次用料單號」、材料及本次實際用量，再按「確認扣除物料」。

只填本次用掉的數量，不填累計數量，也不要把整批叫料量直接當作用量。系統扣除物料總庫存，剩餘未用材料保留；其他 BOM 計畫已預留的物料不可挪用。

保存後在「實際用料紀錄」核對使用前、實際用量及剩餘庫存。成品已收齊的生產單仍可補登實際用料；已取消的生產單不可繼續登記。

### 5. 接收本批成品

成品實際送達自己的出貨倉庫後，在原生產單按「登記本批成品實收」。填寫本批入庫單號與本批件數，再按「確認保存」。

本批件數不得超過待收成品量。保存後自動建立關聯入庫單與逐件庫存；部分到貨時顯示「部分成品到貨」，全部收齊後顯示「成品已收齊」。這一步不會自動扣除物料。

### 6. 補填入庫費用並配櫃

在「成品實收與入庫」按「查看入庫／配櫃」，核對本批成品明細，從入庫單補填或修正費用，再進行配櫃。

費用未知時維持「待填費用」，明確免費才填 `0`。配櫃前若出現費用未填提醒，核對後可依介面確認繼續；商品仍須符合櫃位品質、包裝及出貨條件才可出貨。

生產模組不會將物料費與加工費自動計算為成品成本；成品成本統一在入庫單管理。

## 各操作對庫存的影響

| 操作 | 物料總庫存 | 成品庫存 |
| --- | --- | --- |
| 確認生產下單 | 不變 | 不變 |
| 確認物料叫貨 | 不變 | 不變 |
| 登記物料實收 | 增加本次實收量 | 不變 |
| 登記實際用料 | 減少本次實際用量 | 不變 |
| 登記成品實收 | 不變 | 增加本批成品量 |
| 取消未交成品 | 不自動退料 | 已收成品保留 |

例如：生產 100 個保溫杯，工廠回報需要 30 個外殼。假設起始物料與成品庫存皆為 0，且沒有其他異動：叫料時庫存不變；實收外殼 30 個後在庫為 30；登記實際用掉 25 個後剩 5 個；第一批收到成品 40 件時，成品增加 40 件、待收 60 件，外殼仍為 5 個。此例只說明各事件的記帳差異，不代表完整 BOM 或材料耗用比例。

## 調整、取消與結案

| 需求 | 操作及結果 |
| --- | --- |
| 更改交期或備註 | 在尚未結案的生產單按「調整交期／備註」 |
| 更改生產總數 | 按「修訂生產數量」，填新的總數而非增減量；不得少於已實收數。非草稿修訂至等於已收數時會收齊結案 |
| 工廠不再交付剩餘成品 | 按「取消未交成品」並填原因；保留已收成品與已用物料，不自動退料 |
| 同時不再採購剩餘材料 | 到各關聯物料採購單另行取消未收部分；取消生產不會連帶取消採購 |
| 成品收齊後才收到用料回報 | 仍可登記實際用料，核對可用物料數量後保存 |

取消後未提供重新開啟生產單的流程。取消前先核對仍需登記的用料及採購進度，不以取消生產修正已經發生的收貨或耗用。

## 完成後驗證

- 在生產單核對成品商品、工廠、訂購數、已收、待收與取消量。
- 每批成品都有關聯入庫單，件數與實際收貨一致；費用與配櫃狀態可追查。
- 「關聯物料採購」中的供應商及收貨紀錄正確。
- 「實際用料紀錄」與物料歷史帳一致，未用餘料沒有因成品入庫被再次扣除。
- 「生產單操作紀錄」保留數量與狀態版本，能追查調整經過。

## 常見問題與排錯

| 遇到的狀況 | 處理方式 |
| --- | --- |
| 沒有 BOM，無法判斷是否能下單 | 本指南的工廠回報流程不需 BOM；不要混用既有 BOM 計畫的預留／發退料流程 |
| 物料清單找不到某材料 | 核對材料是否啟用、所屬供應商是否與採購單一致 |
| 實際用料提示庫存不足 | 核對物料實收、已登記耗用，以及其他計畫的預留；不要虛增收貨繞過限制 |
| 成品實收超過待收量 | 確認填的是本批而非累計數量；若生產總量確實增加，先核對並修訂原生產數量 |
| 單號已存在或保存結果不明 | 先查看原單、關聯入庫及用料紀錄，不要換單號重送同一筆實際事件 |
| 提示生產單已更新 | 重新整理、核對最新數量與狀態後再操作 |
| 入庫後不能出貨 | 檢查配櫃、品質、包裝、櫃位出貨資格及其他占用限制 |

若已保存錯誤的實收或用料，先保留單號與回報依據並查明紀錄。本文不提供任意撤銷已入帳資料的流程，也不建議用重複登記抵銷錯誤。
