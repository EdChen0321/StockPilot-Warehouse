# 實際出貨與成本配方

固定 shipping 工具：view=summary、status=all、account_id=''、search=''、as_of=''、offset=0、limit=50。start/end 為台北實際出退貨事件日期，含結束日；不支援依下單來源或訂單狀態篩選。

- 出了多少貨／實際出貨成本用一次 shipping，沿既有 shipping_statistics，不需另用庫存單據重算。
- 未指定期間時 start/end 留空，查全部已記錄事件截至今日。全庫事件為零時，內部預設日期不是只查今日；零筆紀錄不代表系統外沒有出貨。
- 出貨訂單數按履約群組、出貨單數按單據分別計算；部分出貨亦計入，撤銷完成不算，實退另列。
- 成本沿最新入庫成本更正，不是售價或所有營運費用；缺成本不當零。不能用訂單總額直接減不同事件期間出貨成本當毛利。
- 本月／上月沿同次伺服器日期範圍；明確期間優先。訂單加出貨問題各查對應工具，不把日期條件解讀為同一批訂單。
- 查「出貨單有哪些／單號狀態」用 inventory shipments；「逐件成本修訂」用 inventory cost_history。要查目前可出貨量則用 inventory summary，不能由歷史出貨推算。

輸出期間、出貨訂單／單據／件數與成本，保留成本缺漏及資料涵蓋限制。不要推測未出貨原因或尚未出貨成本。
